# Dashboard

The Dashboard in mobohubb provides a graphical interface that displays relevant information and key metrics in real time. It helps users quickly access application functions and analyze data with ease. The Dashboard is divided into several sections for easy navigation.

## Sliders

The Dashboard features horizontal sliders that let you quickly navigate between different functions. The five main sliders are:

* **Scan**
* **Task**
* **Forms**
* **Timesheet**
* **Schedule**

You can slide through these options to access the corresponding features.

## Today

The **Today** section displays the current date if you have not clocked in yet. Once you clock in, it shows the elapsed time and the exact clock-in time. Tapping this section gives you quick access to the Timesheet feature for more detailed time tracking.

## Upcoming Shifts

The **Upcoming Shifts** section shows the shifts that are assigned to you. If no shifts are scheduled, the system will display a message stating "There are no scheduled shifts." Tapping this section opens the Schedule feature where you can see more details.

<Image align="center" width="30% " src="https://files.readme.io/18e2a2362654b35f5f117d1f3bde88ef70964d8e932d4a39d34715b2b72fa37f-image.png" />

## Latest Activities

The **Latest Activities** section displays the five most recent activities along with their timestamps and icons. This section helps you quickly review what actions have been performed. Tapping it will take you to the "My Activity" feature for a detailed view.
