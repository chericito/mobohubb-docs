**In this guide you'll learn:**

* **Add Users:** Include new users for the device.
* **View Logged-In Users:** See which users are currently active on the device.
* **Change Site:** Switch the site if the same user has access to more than one site.

***

# Profile

1. **Open** the side menu: Tap the **hamburger button** at the upper left corner of the app.

2. This will open the side menu. **Click** the name section to open the profile selection menu.

## Add Profile

To add a new profile:

1. **Tap** **Switch User**.

## Change Profile

1. **Tap** on the name area.

2. **Select** other profile.

<Image align="center" className="border" border={true} width="30% " src="https://files.readme.io/22b7c5fd92aaebb9957907e8ded0d17496fd7c3e28d69e935f1fab0a550d7cd1-image.png" />
