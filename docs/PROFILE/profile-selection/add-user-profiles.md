**In this guide you'll learn**

* Where to find the **Add user** option in your profile
* How to log in using **Username and Password** credentials
* How to **switch** between users or **remove** a user profile

***

You can add new user profiles to the **mobohubb** app using the **“Add user”** button, allowing multiple people to log in from a single device. These users must log in using **Username and password** authentication. You can also see or remove any users previously logged in on your device.

## Steps to Add a User Profile

1. **Open** the side menu: Tap the **hamburger button** in the top-left corner of the screen.

<Image align="center" width="30% " src="https://files.readme.io/689f005c3361115543f2d75d00b4556824b4fa553c83b438850fd41ef917fcda-image.png" />

2. **Access** your profile:

* Tap on your profile picture or name in the side menu to open **Profile Identification**.

<Image align="center" width="30% " src="https://files.readme.io/84a574a11a33f45ac3991ddf0d11f72a390d28ccfe1c90571bc870b1ba400d03-image.png" />

3. **Tap** **“Add user.”**

<Image align="center" width="30% " src="https://files.readme.io/8799f97d3539efa2428d7f64438e560f0534abfa052835dea91af2fe70bd7a6d-image.png" />

4. **Log in** with **Username and Password**:

<Image align="center" width="30% " src="https://files.readme.io/a97898e875e0f58fb9b1d38837254ca6e52fe5f9b22ad369d8dfe094b9afb73c-image.png" />

* Enter the credentials for the new user.
* Wait for the authentication to complete.

> **Note:** If a user appears as **“logged out,”** they must log in again with their username and password credentials.

## Removing a User Profile

1. **Navigate** to **Profile Identification** in the same way described above.
2. **Locate** the user you want to remove.

<Image align="center" width="30% " src="https://files.readme.io/92f562b569a2e17c298583e43bf6cb88f9babf14ef64594e929d6ebecb9aea62-image.png" />

3. **Tap** the **trash bin** icon next to that user’s name.

![](https://files.readme.io/d4b4d4327b092ff751800885654b32be8f796e9ea41ca2dacd7e6b4f88865001-image.png)

4. **Confirm** removal by tapping **“Remove.”**

Once removed, the user’s account can no longer be accessed on this device unless they log in again.
