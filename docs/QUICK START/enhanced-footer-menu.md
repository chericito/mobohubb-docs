# Enhanced Footer Menu

The Enhanced Footer Menu in the mobohubb mobile app has been redesigned to improve user navigation and efficiency. It now displays five default options, with the addition of a dedicated Home tab that serves as a central hub for accessing work and organization-related features.

The Home tab provides quick access to essential functions such as checking in/out, viewing tasks, accessing schedules, and managing other critical operations. This streamlined design simplifies day-to-day activities and enhances the overall user experience.

> **Note:** The Footer Menu can be modified by administrator users through the mobohubb portal in the [mobile configuration](https://mobohubb.readme.io/docs/site-management#/mobile-configuration), allowing for tailored navigation that meets your organization's specific requirements.
