# Log in the Web App

1. visit [https://webapp.mobohubb.com/sign-in](https://webapp.mobohubb.com/sign-in)
2. Fill in the user name and password fields. These are the credentials assigned to each user by the administrator.

![](https://files.readme.io/89a5918fe362bb3ee8130feaddc6bbcd7fb51c9b844c0bcfbbdd3fdb66e0ec18-image.png)

3. Sign in.

## Forgot Password?

1. You can easily recover your password by pressing the "Forgot Password?" button in the log in screen.

<Image align="center" className="border" border={true} width="50% " src="https://files.readme.io/b172977b364b8915c3f23096be14868e2e33ce528d31c5a4dc401943fb0a1eca-Screenshot_2025-02-07_at_10.12.26_AM.png" />

<br />

2. Fill in your username and press "Send Code".

<Image align="center" className="border" border={true} width="50% " src="https://files.readme.io/15960cf8bc7409328da36b41917bc4aad29805b8666ad568f150e7590e5f51c5-image.png" />

3. You can receive the code via email or SMS, based on the organization preferences.

<Image align="center" className="border" border={true} src="https://files.readme.io/686689c2c68b91b239cd4e8282e739061f128b652e4b4e9c65643c1a86f29637-image.png" />

4. Fill in the fields

<Image align="center" width="50% " src="https://files.readme.io/5582e21793f129e896fba966843a3be6e20cac5aa722e41454b1418774f3b7a3-image.png" />

5. Your password is now updated, and you may log in with your new password.
