### Metadata Description

Learn how to log in to the **mobohubb Kiosk** interface designed exclusively for Site Administrators. This guide explains how to enter administrator credentials, select an active site, and initiate a session where employees can use their PINs to check in/out and manage break times.

**In this guide you'll learn**

* How to log in to the Kiosk using Site Administrator credentials
* How to select an active site for the session
* How the Kiosk session allows employees to check in/out and manage break times

***

<Tabs>
  <Tab title="Login">
    The Kiosk login is intended for **Site Administrators** only. To log in to the Kiosk, enter your Site Administrator credentials and press "Login".

    ![](https://files.readme.io/c11a08951425427b78c9cc87e9936bfe157dacb1828700d61fa064a7dd84ded3-Screenshot_20250218_155732_mobohubb_kiosk.png)
  </Tab>

  <Tab title="Select Site">
    After logging in, select one of the sites. Only the sites that have been previously set as active for Kiosk by the Site Administrator will be available. Use the search bar if the list is long to find a specific site.

    ![](https://files.readme.io/ffb015e64f1090d165a220faaf676851fa73c2828feefc795949d8d648449b77-Screenshot_20250218_162126_mobohubb_kiosk.jpg)
  </Tab>

  <Tab title="Check-In">
    Once a site is selected for the session, all employees/users can enter their **PIN** to check in, check out, and manage break times.

    ![](https://files.readme.io/5c481143e77f2c2c43e7fc3442125dd2bddc7f992f47bcdac9a3dbccb408a96c-Screenshot_20250218_162156_mobohubb_kiosk.jpg)
  </Tab>
</Tabs>
