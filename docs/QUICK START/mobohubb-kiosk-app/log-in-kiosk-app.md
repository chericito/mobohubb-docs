**In this guide you'll learn**

* How to log in to the Kiosk using Site Administrator credentials
* How to select an active site for the session
* How the Kiosk session allows employees to check in/out and manage break times

***

# Log in

<Accordion title="Prerequisites" icon="fa-info-circle">
  The Kiosk login is intended for Site Managers, Organization Managers and Editors only (Refer to our Security Groups management section).
</Accordion>

To log in to the Kiosk, enter your Site Administrator credentials and press **"Login"**.

<Image align="center" width="30% " src="https://files.readme.io/a9d825738e38774965b900ceaf310462cfd66793ff8f8ee58960dc2365fe9e61-Kiosk_1.png" />

After logging in, select one of the sites. Only the sites that have been previously set as active for Kiosk by the Site Administrator will be available. Use the search bar if the list is long to find a specific site.

<Image align="center" width="30% " src="https://files.readme.io/22c417ff4b161ad75445ccb4e662fd523764e21b815396f218f9f61e29759883-Kiosk_2.png" />

Once a site is selected for the session, all employees/users can then enter their **PIN** to check in, check out, and manage break times.

<Image align="center" width="30% " src="https://files.readme.io/8e904d641a23b7c9f5e57b90e52ed06387f288ed1404818b0ab6480dee0f5aec-Kiosk_3.png" />
