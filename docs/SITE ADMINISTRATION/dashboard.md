The redesigned dashboard is divided into **global indicators**, **user activity**, **top forms**, **incomplete activities**, and a **planned vs. done** comparison. It also features new graphs that simplify data visualization. You can show data by **day**, **week**, **month**, or a **custom time range** using the GUI under the “Header” block.

## **Quick Filters**

Click on the corresponding option to filter by **day**, **week**, or **month**.

## **Custom Filters**

To select a **specific range**, click the appropriate option.\
You can also move both **start** and **end** indicators in the interactive calendar to define your custom date range.

<Image align="center" className="border" border={true} src="https://files.readme.io/d2eef727dc8fa854609399b60df252a5169c814d1c2b2f2aadf8930c1f056e39-image_1_copy.png" />

> **Note:** The range you set will display above "Global Indicators"

## **Global Indicators**

Displays a bar graph showing totals for each indicator:

<Image align="center" className="border" border={true} src="https://files.readme.io/f7a5fc45d55f27d8eaaaea2c9e541f81b6b0d6ae3583600d8569b648f06f4cf8-image.png" />

* **Users**: Total registered users in the system
* **Scan Points**: Total number of created scan points
* **Devices**: Total devices (phones, tablets, etc.) currently in use
* **Tasks**: Total tasks created
* **Forms**: Total forms created

***

## **User Activity**

Displays a line graph where each line represents a different activity:

<Image align="center" className="border" border={true} src="https://files.readme.io/bab2a2719288ca5b809a9253f3d822309b688f02a51500966a70a0260be6e856-image.png" />

* **Forms Activity**: Number of form submissions within the chosen time range
* **Task Activity**: Number of tasks completed in the same period
* **Scans Activity**: Number of scan points scanned
* **Timesheet Activity**: Number of time clock entries made by users

***

## **Top Forms**

Shows the most frequently used forms and their submission counts. This helps identify which forms are most popular or critical:

<Image align="center" className="border" border={true} src="https://files.readme.io/e70e2fcf1b2539f235403d7b321c886b8f8b99a3a3b29827994236f9483430d2-image.png" />

* **Forms**: Sorted by the highest to lowest submission counts

***

## **Incomplete Activities**

Shows a line graph highlighting the total **uncompleted** activities (marked as “No Activity Exception”) in a given time range. Each category is color-coded:

<Image align="center" className="border" border={true} src="https://files.readme.io/3d6f618b8e8bd0a6ae6eb3315254f8e7c41f5420c3fcb20e4a9d12d89dc212a1-image_3.png" />

* **Forms**: Incomplete mandatory forms
* **Task**: Tasks that weren’t finished
* **Scans**: Scan points not checked
* **Timesheet**: Missing time clock entries for required shifts
