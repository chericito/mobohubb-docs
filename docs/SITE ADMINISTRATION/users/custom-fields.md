Custom Fields allow you to attach additional data to a user's profile. These blank fields are fully customizable, enabling you to include information that isn’t covered by the standard mobohubb fields. You can add as many fields as needed; simply click the "+" button next to the last empty field to add more.

If you need to access the user profile, follow these steps:

1. **Navigate** to the "Users" section.

2. In the current window, **check** the box next to the user you wish to personalize.\
   **Note:** You can modify only one user at a time, so do not check more than one user's box.

3. On the right side of the interface, **click** on "Edit."

4. **Click** on the "Custom Fields" tab.

5. **Fill in** the empty fields or **add new fields** as required.
