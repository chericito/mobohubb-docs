When the shifts are published in the schedule and you have previously accepted them, you can start the shift to complete the assignments. You may perform this action when the shift’s start hour says.

The shifts can be configured to be enable the integrated clock feature or disabled the integrated with the clock. This may describe the action to start and finish the shift.

## Start shifts with no integrated clock

The way to start a shift which does not have the integrated clock is through "Check-in" and "Check-out"

To start a shift with no integrated clock, access “shift details” in the schedule feature. You can access the Schedule using the footer menu.

Note: Remember you can use the upcoming shifts section, or the sliders section to access the Schedule feature. Visit our Schedule management to see more information.

Use the planner to access the shifts details.

![](https://files.readme.io/dd10a4cf51d88d4eab57ca85bb57ae496c7625d8fb7c0dcc9be0a4c1bb53283a-3189DF6D-7A4B-4CBB-B733-DAC3E7AFA936.png)

<br />

Use the Check in button.

You need to previously have accepted the shift.

When you check in into the shift the work status will change from “not Started” to “Started.” This will be visible for the administrator.

![](https://files.readme.io/86b8fdf3be194032df2eb3108f4a8d70e6f73bfe6956d40f68a0240cf517c6e6-0CFF647A-0A77-4EE8-952E-CE0423E22DB9.png)

<br />

Complete activities.

If there are activities associated with the shift, you can carry them out throughout the shift.

Note: Go to “How to view task forms scans associated with the shift” for more information.

## Start shifts with integrated clock

The way to start a shift with integrated clock is through "Clock in" and "Clock out"

To start a shift with integrated clock, access “shift details” in the schedule feature. You can access the Schedule using the footer menu.

Note: Remember you can use the upcoming shifts section, or the sliders section to access the Schedule feature. Visit our Schedule management to see more information.

Use the planner to access the shifts details.

You can scroll down to see details of future shifts. 

You can tap on each shift to see the shifts details. 

<br />

![](https://files.readme.io/2403d04b4d57349d00048d417d82d8989b432de63e6b48623974a3f1505ef0a8-B7B0B475-89FA-415E-A34E-C1F288989B73.png)

<br />

  

Use the “Open timeclock” button.

You need to previously have accepted the shift.

You will be redirected to the “Time” feature.

<br />

![](https://files.readme.io/44e932afbbc4f8dfbc7425b4e63b6f1c427f4cf18d89a776d42925d5df68afb2-B61F0EE5-1ED3-4877-92A8-ABAFF6C5C12D.png)

<br />

Use the “Clock in” button to start the shift.

The “Time” feature will show the shift it is associated with. This label will show the name of the shift, the start hour, and the color associated with it.

When you Clock in into the time feature, the shift will remain in the clock and the work status will change from “not Started” to “Started.”

![](https://files.readme.io/bc2ccabc605d8794ab0113bdde4d4f91ddc8d5df3aa00d108ad406c225b558f0-6F0BB3CD-AF9E-47E8-944B-417BCD0314E3.png)

<br />

Complete activities

If there are activities associated with the shift, you can carry them out throughout the shift.

## End shifts with no integrated clock

When the shifts are published in the schedule and you have previously started them, you can end the shifts to indicate their completed. You may perform this action when the shift’s end hour shows.

The way to end a shift which does not have the integrated clock is through  "Check-out"

To end a shift with no integrated clock, access “shift details” in the schedule feature. You can access the Schedule using the footer menu:

Use the planner to access the shifts details.

You can scroll down to see details of future shifts. 

You can tap on each shift to see the shifts details. 

  

![](https://files.readme.io/1e78dd05200926d0e0c439ec59643b59ba6f00d09015bc10d8a9176eb05f4416-E597DBF7-43B7-47A9-9362-2B36C9E8CB51.png)

Use the “check out” button to end the shifts.

This will change the work status from “Started” to “Completed.”

![](https://files.readme.io/7fd59c8d2a0da4911103121fd6322e382c40327eaa3c8608d87e597c400948f7-2ECFD078-6500-4FC1-86BC-3E981FC0C1CD.png)

## End shifts with integrated clock

The shifts integrated into the clock will end automatically so you don't need to perform any action. They will mark as “Completed” in the schedule.

If you need to end the shift before the set end time you can do it by the clock.

Use the planner to access the shifts details.

<br />

In the scheduler click on “Clock out.”
