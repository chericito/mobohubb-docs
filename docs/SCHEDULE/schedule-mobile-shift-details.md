SHIFTS DETAILS (MOBILE

​​

Use the planner to access the shifts details.

You can scroll down to see details of future shifts. 

You can tap on each shift to see the shifts details. 

  

![](https://files.readme.io/d3d65983d462cab7dc58e1f3ec26da5041d0b6932fc0b805d424046b6e88abc2-E4F12563-9293-4804-B826-9B07F74CB212.png)

<br />

Description

Here you can see the details of each shift, show as a list with the relevant information: 

![](https://files.readme.io/f7be62e3bd3657ff9c995a497960368a5ed84fbe72f2132fc194c54818891ac3-F5D372AD-6156-4D07-9F56-DAD7CD95C730.png)

<br />

Role: you can see the role assigned to the shifts.

Start day: you can see the starting date of the shift.

Start hour: you can see the starting hour of the shift. 

Total hours: you can see the total hours of the shift.

Description: You can see the description provided by the administrator.

Note: You can see the notes for other information.

Location: you can see the location where the shifts may be performed. 

Attachments: you can see file attachments. 

Shift status: This can be approved, pending for approval, request a replacement, overlapping.

Work status: this can be started or not started. 

<br />

Use the download button to download the attachments in your device.

![](https://files.readme.io/691c12dbf4604a56d43fe753921d187ee161ea12378af444181c136c3aa352bf-DB425165-4EF7-45E7-A0ED-139CF6590C6B.png)

<br />

Note: This button won’t be able if there are no attachments.

Teams

Use the team section to display the other users who have been assigned the shift.

<br />

For each user you can see the Name, and role. Scroll down to navigate.

![](https://files.readme.io/f67d1e5b58b0e205134c091cfcf2f854396e26822486571b112ef8472225ddf0-4520E46D-D985-49CA-9B8B-0941E7A323A8.png)

Activity (tasks/ scans/ forms)

This section will show you if there is any activity related to the shift. This refers to tasks, forms, or scans you may complete to successfully complete the shift.

Here you can see the category of each activity.

![](https://files.readme.io/9f587c7201b6899ea3df615a235ee3de08d8e572fdbd6e9a5bba057186bff4dd-8FB7DDB2-0A34-498B-BFFE-7941B288599D.png)
