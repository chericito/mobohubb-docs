You can perform several actions from the Schedule.

From the toolbar, you can manage requests, actions and Publishing options. From this menu, select "Actions".

<Image align="center" className="border" border={true} width="40% " src="https://files.readme.io/dea88a20b474ea3c4c173c3e9b922e956649fb244b685457ca98bb5db0c52697-image.png" />

In this screen you'll see the following actions:

* **Unpublish Week**: Converts published shifts to drafts, hiding them from mobile users.
* **Copy From Template**: Opens a window with ready-to-use templates.
* **Clear Week**: Deletes all **not started** shifts in the current view.
* **Remove Assignments**: Marks all shifts as unassigned, letting users claim them.
* **Save as Week Template**: Saves the present week’s layout as a reusable template.
* **Copy Previous Week**: Brings over last week’s shifts into the current week.
* **Add or Edit Unavailability**: Manage the times users are marked as unavailable.
* **View Conflict**: Highlights warning or alert messages for immediate attention (e.g., overlapping shifts or missing acceptances).
* **Export PDF**: Downloads the current view as a PDF (appears in **“Downloads”** if it exceeds file size limits).

# Clear Week

The **Clear week** function lets you remove all shifts—draft, published, or unassigned—in a specific week, provided they haven’t already been started by employees.

1. **Open** your schedule and use the **Date Selector** in the toolbar to find the week you want to clear.

2. **Click** **“Actions”.**

3. **Choose** **“Clear week.”**

4. **Confirm** your choice by selecting **“Delete.”**
   * All shifts in that week are discarded except those that have already started.

> **Note:** Shifts that users have begun (checked in to) cannot be removed with **Clear week**.
