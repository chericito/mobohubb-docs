In this section, you can assign a user a position along with a pay rate and specify the amount of overtime. **This assignment applies individually to each user, even if several users share the same position.**

If you need to reach the user profile, follow these steps:

1. **Navigate** to the "Users" section.

2. In the current window, **check** the box for the user you wish to personalize.

   > **Note:** You can modify only one user at a time, so do not check more than one user's box.

3. On the right side of the interface, **click** on "Edit".

4. **Click** on the "Hourly pay" tab.

5. **Fill in** the empty fields or modify the existing information as needed.

6. **Click** the "Save" button to save your changes.
