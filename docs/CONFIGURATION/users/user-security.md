You can easily modify the permission and usage levels so that a user can access the portal, the mobile app, or both. You can configure roles and tags to associate these parameters with the user and quickly identify them, along with the associated device. To update these settings, switch to the **Security** tab within the user profile and remember to save your changes.

Follow these steps to access and modify a user's security settings:

1. **Navigate** to the portal’s top menu.

2. **Go to "General Settings."**
   * In the top menu, click on **Settings**. This is where you'll find various configuration options for your organization. You may also use the side menu to access General Settings.

3. **Navigate** to the **"Users"** section.
   * In the Site Administration area, click on **Users**.

4. **Select** the user you wish to personalize by checking the corresponding box.

> **Note:** You can modify only one user at a time, so do not check more than one user's box.

5. **Click** on the **"Edit"** button located on the right side of the interface.
6. **Click** on the **"Security"** tab.
7. **Fill in** the empty fields or modify the existing information.

* You can update the **Role**, **Security Groups**, **Device(s)** from which the user may access the platform, and set **type** permissions for mobile and portal web forms completions, among other settings.

5. **Click** the **"Save"** button to apply your changes.
