# Logging into the Mobile App

Employees must be **invited by an administrator or manager** who has authority to create new users on the Mobohubb web portal. The admin links each user’s name, email, and phone number to the portal, ensuring they can log in through one of Mobohubb’s security protocols.

### No More Domain and Pin

Previously, users needed to enter a domain and pin to verify identity. Now, **Mobohubb** offers multiple login methods:

* **Email verification code**: Enter a code sent via email.
* **SMS verification code**: Enter a code sent via text message.
* **Username & password**: Use credentials created by your organization or system admin.

If you’re an existing user logging in for the first time, you can still use your domain and pin initially. However, you’ll then be required to update your email and phone number to take advantage of the new login methods.

## Email Invitation

When invited via email, workers receive a message containing their **username** (the same email) and an **auto-generated password**. The first time you log in, you’ll be prompted to change this password or request the admin to change it on your behalf.

![](https://files.readme.io/f5f5951628aafff945bd860a1a027b59bc222caf397a1201fd3b9f3125e673f3-image.png)

> **Note:** For the **initial email invitation**, use **Username and Password** to log in.

## SMS Invitation

When invited via SMS, workers receive a text message containing access information and a verification code.\
![](https://files.readme.io/47bb56b4f277b2fb83d6153f42b3dd3b24c03526c1a7bca0c339aaef17b38335-image.png)

> **Note:** For the **initial SMS invitation**, use the **SMS verification code** to log in.

# Logging into the Mobile App

Employees wishing to use the Mobohubb mobile application must have received a prior invitation from an administrator or manager who is authorized to create new users on the Mobohubb web portal. This administrator will be responsible for linking the employee's personal information, including name, email address, and phone number, to the organization's portal. This information is essential as the log-in methods require it. That is why the data must be updated whenever there is a change in users.

> 👍 No more Domain and Pin
>
> Previously, access to the mobile application required the introduction of a domain and a pin to verify the user's identity. Currently, we have improved our security protocols to streamline the access process and validation of the user's identity, so we provide several options for users to log in:
>
> Email verification code: you will receive an email with a code that you must enter on the login screen.
>
> SMS verification code: you will receive a text message with a code that you must enter on the login screen.
>
> Username and password: you can create a username and password that you will use to access the platform.
>
> If you are an existing user and this is the first time you access the platform, don’t worry: you can use the domain and pin as a first step. However, you must then fill in the fields corresponding to the email and mobile number, which are essential in using Mobohubb.

Before using any of the three login methods, it is necessary to differentiate the type of invitation received. There are two ways for users to receive the invitation: by email or by SMS, and each has a unique login procedure.

## Email Invitation

Once invited, workers will receive an email, with access data to the mobile application, consisting of a username (which is the email) and a password that will be generated automatically. You can find this password in your email inbox.

<Image align="center" className="border" border={true} src="https://files.readme.io/f5f5951628aafff945bd860a1a027b59bc222caf397a1201fd3b9f3125e673f3-image.png" />

It is imperative that employees change this password the first time they access the application or ask the portal administrator to change it for them. It is important to remember that this request is only necessary the first time a user is invited to the organization.

> **Note:** When you receive the initial email invitation, you are expected to use Username and password to log in.

## SMS Invitation

Once invited, workers will receive an SMS with access data to the mobile application.

![](https://files.readme.io/47bb56b4f277b2fb83d6153f42b3dd3b24c03526c1a7bca0c339aaef17b38335-image.png)

Note: When you receive the initial SMS invitation, you are expected to use SMS verification Code to log in.
