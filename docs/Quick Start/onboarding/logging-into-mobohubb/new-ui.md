# New User Interface

We have revamped Mobohubb’s graphical interface to make it more **modern**, **intuitive**, and **customizable**. You’ll notice a refreshed color palette, reorganized layout, and new customization options to suit your preferences and needs.

> **Highlights**
>
> * **Updated Color Palette** for a harmonious look
> * **Reorganized Layout** for easier navigation
> * **Customization Options** to modify design, organization, and color

## Customizable Views

It is now possible to **modify views** in Mobohubb. You can change the displayed columns and hide any data you don’t need. Once customized, you can **save** and **retrieve** your [customizable views](https://mobohubb.zendesk.com/hc/en-us/articles/25663316351629-Customizable-views) later, avoiding repetitive setups. You can also apply **quick** or **advanced** filters to show only items meeting specific conditions.

***

## Automatic Pagination

We’ve replaced **traditional pagination** with **automatic pagination**. Simply **scroll** to load more items—there are no longer “Next” or “Previous” buttons. This offers a seamless browsing experience, allowing you to see all elements in a list without manual page changes.

We have revamped the platform's graphical interface to offer a more attractive, intuitive, and customizable experience. We have changed the color palette of the interface to give it a more modern and harmonious look. We reorganized the layout of the interface elements to facilitate navigation and access to the platform's functions and options. We have added the ability to customize the interface according to preferences and needs, modifying some aspects in design, organization, and color.

![](https://files.readme.io/8cc3101a2b2bd4760a0375e95cec373d1e559519e3b0afa21f2f6f650bb6e976-image.png)

Mobohubb has implemented a new user interface to improve the interaction between user and web application, which complies with the following standards:

The side menu: This is a vertical bar located to the left of the screen that contains the main tools of the application. The side menu allows the user to quickly access the different sections or features of the application, such as dashboard, configuration, productivity, exceptions, administration, and favorites. At the end of the menu is the “Profile settings” button; this allows us to access the quick settings menu, which includes editing the menu, accessing the profile, and viewing all the general settings. This menu can collapse.

![](https://files.readme.io/bb11c0f7acc60f9b1fd9a526f5a40a81f50c0bf80a7ee5e99a08ef824926315e-image.png)

Top Menu: This is where you'll find the Mobohubb news, where you can see your alert messages, and the user drop-down menu, where you can access your profile and log out of the online portal. This bar will notify you when your subscription is ready to expire or show you news about the platform.

![](https://files.readme.io/77f9fb3139ce233fb525ee05d6770537d7dbdb6e72636053b1ab24b504bb3a94-image.png)

<br />

Header block: This displays the title or name of a section or window.

![](https://files.readme.io/346e796e7107d98264b6f854b0750570f950f174b4805db9959140c407117d2e-image.png)

Organization Structure Selector: Using this feature, you can select one of the organization’s multiple sites. It acts as a global filter for most of the views of the application.

![](https://files.readme.io/e587a6ebc457ccefdc2367dc5403db0f006247d9dc33f1a247fd3fd695917d34-image.png)

Main content: This is the space that displays the content or information that the user has selected.

![](https://files.readme.io/276e9e9abe53a6c7fb431b3b34622fc9c7679996b376facff218233ae9c7a8b4-image.png)

The General Settings interface is where you will find the other tools and settings; it is organized by categories so that the user can more easily locate the required functions.

![](https://files.readme.io/ddd898468aa518fcbb0e357f25764a96486b8661ae3fbeb884822daa741c23bf-image.png)

It is now possible to modify views in Mobohubb. You can alter the view and content that is displayed for each feature. By hiding data in columns that are not needed, you can display only the information you wish. You can store and retrieve your [customizable views](https://mobohubb.zendesk.com/hc/en-us/articles/25663316351629-Customizable-views) later. You can also apply quick or advanced filters to show only items that meet certain conditions.

We no longer use traditional pagination: we now use automatic pagination. Therefore, you cannot advance through pages using buttons; however, simply by scrolling, automatic pagination allows you to see all the elements in the view without having to click on the next or previous buttons.
