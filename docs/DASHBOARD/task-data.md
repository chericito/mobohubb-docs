**In this guide you'll learn**

* What **Task Data** includes
* How to **filter** and manage task records
* How to **export** your current view to Excel

***

<Image align="center" className="border" border={true} width="80% " src="https://files.readme.io/a81d6bf2fa7d5c7e9287901cce90ffab17830f94857415cbf7989b3e821363ca-image.png" />

**Task Data** is generated when a user completes a task on their device. Each record can include the **task name**, **description**, **start date**, **due date**, **status**, **task manager**, and any **notes** or **attachments** linked to that task.

## Export and Manage Task Data

1. **Navigate** to **“Task Data”** in the **side menu** of the portal. (You may also use the **search bar** in the top menu.)

<Image align="center" className="border" border={true} width="80% " src="https://files.readme.io/b78b27ca243a078fce1d78408f3aefce11b98bac2b578cec10b72c9dc3f513d0-image.png" />

2. **Filter** your data using **quick** or **advanced** filters:

* Add as many rules as needed by clicking **“Add New Filter”.**
* **Apply** the filters once you’re done refining.
* See [Filters](https://mobohubb.readme.io/docs/filters#/) (or refer to your internal “Filters” guide) for more details on advanced filtering.

1. **Review** all pertinent information for each task in the main table:
   * The **upper checkbox** selects all visible data if you need a bulk action.

2. **Click** on **“Export”.**
   * Make sure you have **selected** all relevant rows first.

3. **Select** **“Export current view”.**
   * If the file is within size limits, your **Excel** download starts automatically.
   * If it exceeds limits, you’ll find the file in **“Downloads”** on the platform.
